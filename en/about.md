## Where we begin

Our work starts with mechanics, rules, interaction and the question of how an
idea becomes an understandable experience. Software may support that process,
but it is not the studio's commercial promise.

## Open when software emerges

Supporting software is offered exclusively as open-source software. A free
installation path outside app stores remains documented. Optional store
versions may provide a more convenient distribution route.

## Licensing

Where identified by the individual project, Nijida software and specification
materials use the Apache License 2.0. The licence file in the respective
repository is always authoritative.
