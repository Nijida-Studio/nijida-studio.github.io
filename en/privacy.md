## Principle

Nijida itself does not collect, store, analyse, sell or profile personal usage
data. This principle applies to the websites and to software published by
Nijida unless an individual project transparently states otherwise before use.

## Websites

Nijida websites use no audience analytics, marketing or tracking services,
externally loaded fonts, embedded video, maps or social widgets, contact forms,
or non-essential cookies.

## Software

By default, Nijida software contains no telemetry, advertising, tracking SDKs,
cloud synchronisation or automatic crash-report transmission. Settings and
content remain local unless a project explicitly describes another function.

## Technical delivery by GitHub

Source code, downloads and this test site are delivered using GitHub services.
GitHub processes technical connection data under its own rules. Nijida cannot
control that processing and does not access personal visitor profiles.

- [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [About GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## App stores and distribution platforms

Apple, Google and Microsoft may process data for store operation, payments,
licensing and security under their own terms. Data processed exclusively in
those systems remains governed by the provider. If a platform later exposes
personal data to Nijida, the project-specific notice must be updated before
release.

- [Apple Privacy Policy](https://www.apple.com/legal/privacy/)
- [Google Privacy Policy](https://policies.google.com/privacy?hl=en)
- [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement)

## Changes

Features requiring data processing may be released only after an explicit
project decision and updated information.
