## Unser Ausgangspunkt

Im Mittelpunkt stehen Spielmechaniken, Regeln, Interaktionen und die Frage, wie
aus einer Idee ein verständliches Erlebnis wird. Software kann diesen Prozess
unterstützen, ist aber nicht das eigentliche Geschäftsversprechen.

## Offen, wenn Software entsteht

Begleitende Software wird ausschließlich als Open-Source-Software angeboten.
Sie kann kostenlos außerhalb eines Stores installiert werden. Optionale
Store-Versionen können die bequemere Verteilung ermöglichen; die freie
Installationsmöglichkeit bleibt dokumentiert.

## Lizenzierung

Von Nijida veröffentlichte Software und Spezifikationsmaterialien verwenden,
soweit am jeweiligen Projekt ausgewiesen, die Apache License 2.0. Maßgeblich
bleibt immer die Lizenzdatei des betreffenden Repositories.
