## Grundsatz

Nijida erhebt, speichert, analysiert, verkauft oder profiliert selbst keine
personenbezogenen Nutzungsdaten. Dieser Grundsatz gilt für die Webseiten und
für von Nijida veröffentlichte Software, solange ein einzelnes Projekt nicht
vor der Nutzung transparent etwas anderes ausweist.

## Webseiten

Die Nijida-Webseiten verwenden keine Reichweitenanalyse, keine Marketing- oder
Trackingdienste, keine extern geladenen Schriftarten, keine eingebetteten
Videos, Karten oder Social-Media-Elemente, keine Kontaktformulare und keine
nicht erforderlichen Cookies.

## Software

Nijida-Software enthält standardmäßig keine Telemetrie, Werbung,
Tracking-SDKs, Cloud-Synchronisation oder automatische Übermittlung von
Absturzberichten. Einstellungen und Inhalte bleiben lokal, sofern das jeweilige
Projekt nicht ausdrücklich und vorab eine andere Funktion beschreibt.

## Technische Bereitstellung durch GitHub

Quellcode, Downloads und diese Testseite werden über Dienste von GitHub
bereitgestellt. GitHub verarbeitet beim Aufruf eigener Dienste technische
Verbindungsdaten nach eigenen Regeln. Nijida kann diese Verarbeitung nicht
steuern und greift nicht auf persönliche Besucherprofile zu.

- [GitHub-Datenschutzerklärung](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement)
- [Informationen zu GitHub Pages](https://docs.github.com/de/pages/getting-started-with-github-pages/what-is-github-pages)

## App Stores und andere Vertriebsplattformen

Apple, Google und Microsoft können Daten für Store-Betrieb, Zahlungen,
Lizenzierung und Sicherheit nach ihren eigenen Bedingungen verarbeiten. Daten,
die ausschließlich in diesen Systemen verarbeitet werden, bleiben in der
Verantwortung des jeweiligen Anbieters. Falls eine Plattform Nijida künftig
personenbezogene Daten zugänglich macht oder ein Projekt solche Daten nutzt,
muss die projektbezogene Information vor Veröffentlichung ergänzt werden.

- [Apple Datenschutz](https://www.apple.com/de/legal/privacy/)
- [Google Datenschutzerklärung](https://policies.google.com/privacy?hl=de)
- [Microsoft-Datenschutzbestimmungen](https://privacy.microsoft.com/de-de/privacystatement)

## Änderungen

Neue Funktionen, die Datenverarbeitung erfordern würden, dürfen erst nach einer
ausdrücklichen Projektentscheidung und einer aktualisierten Information
veröffentlicht werden.
